# 모바일 디자인 구현 확인

참고 파일은 `src/contents_feed.png`, `src/feed.png`, `src/market_menu_feed.png`이며 원본 파일은 변경하지 않고 Git에서 제외한다. 화면은 React 컴포넌트로 구성하고 색상·간격·폰트·이미지 비율은 `src/styles/mobile.css`의 테마와 공통 변수로 관리한다. 주요 강조색은 PNG에서 추출한 `#A25C54`다.

## 화면 크기

- 기준: 390×844. 좁은 모바일에서는 화면 폭과 실제 가용 높이를 따른다.
- 500px 이상에서는 390:844 프레임을 중앙에 배치한다. 창 높이가 844px보다 작으면 같은 비율로 프레임 폭을 줄인다.
- 긴 콘텐츠는 프레임 내부에서 스크롤한다. 하단 메뉴·주문 버튼은 프레임 하단에 고정한다.
- 디자인 캔버스의 회색 바깥 영역, 설명 제목, 연결 화살표와 기기 상태 표시줄은 앱 UI에 포함하지 않는다.

## 화면별 차이와 필요한 자료

| 화면 | 적용 내용 | 남아 있는 차이 |
| --- | --- | --- |
| 콘텐츠 | 2열 카드, 검색, 분류, 하단 음식 패널 | API 콘텐츠·음식 이미지와 실제 작품명이 표시되므로 회색 더미·예시 문구와 다르다. |
| 숏폼 | 전체 영상, 반응 버튼, 설명, 가게 카드와 2개 버튼 | API의 실제 영상·가게명이 표시된다. API에 없는 좋아요 수는 표시하지 않는다. |
| 가게 메뉴 | 사진 영역, 체크박스, 메뉴 정보, 지도 링크, 하단 선택·합계 | 개별 메뉴 사진 API가 없어 사진 영역은 회색이다. 시장 가게 위치를 가상 점포 번호로 표시하지 않는다. |
| 한국어 주문 | 메뉴, 먹는 법, 수량, 한국어 카드, 결제 안내, 하단 버튼 | 문장과 가격은 실제 주문 미리보기 응답을 따른다. 확인 버튼은 카드 준비만 하며 주문·결제를 접수하지 않는다. |
| 시장 목록 | 지도 영역과 길찾기, 시장 정보, 음식 태그가 있는 세로 카드 | 시장 썸네일이 없는 데이터는 같은 비율의 회색 지도 영역이다. 음식 태그와 가게 수는 실제 API 값이다. |
| 시장별 메뉴 | 검색·실제 메뉴 분류, 사진 영역, 가격·가게, 가게 보기·길찾기 | 메뉴 사진 API가 없어 회색 사진 영역이다. 긴 이름은 실제 데이터 길이에 따라 줄바꿈한다. |

원본 폰트 파일·Figma 원본 노드의 수치가 제공되지 않아 Arial/Pretendard/Noto Sans KR 폴백을 사용한다. 운영체제에 따른 글꼴 차이와 PNG 축소에 따른 치수 오차가 남을 수 있다. 임의의 대체 사진은 넣지 않는다. 추가로 필요한 자료는 메뉴별 사진 또는 메뉴 사진 API 필드, 지도 썸네일, 원본 글꼴이다.

## 검증 범위

각 페이지의 `npm run build`, `npm run lint`와 Edge 렌더링을 확인한다. 320px·390px·1440px에서 화면 폭과 하단 고정 영역을 확인하고 콘텐츠 패널, 숏폼 저장, 메뉴 선택, 주문 수량·합계, 시장·메뉴 검색과 분류를 검사한다. 주문 확인은 `/orders/preview`만 사용하며 실제 가게 등록·수정·결제 요청은 하지 않는다.
