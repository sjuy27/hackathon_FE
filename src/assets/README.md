# 화면 이미지

정적 화면 이미지를 추가할 때는 용도별 폴더와 영문 소문자·하이픈 파일명을 사용한다. 현재 화면의 콘텐츠·음식·영상 썸네일은 API URL로 연결하며 중복 다운로드하지 않는다.

API image_url/thumbnail_url을 우선 사용한다. 메뉴 사진이 없거나 로드에 실패하면 foods/의 음식 참고 사진을 원문 메뉴명으로 연결한다. 시장 카드도 시장별 대표 음식 참고 사진을 사용한다. 출처와 라이선스는 foods/CREDITS.txt에 있으며 My page에서 볼 수 있다. 등록되지 않은 음식에는 임의의 다른 사진을 붙이지 않는다. `src/`의 디자인 참고 PNG는 이 폴더로 복사하거나 화면 리소스로 사용하지 않는다.
