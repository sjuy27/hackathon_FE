# 골목 GOLMOK

전통시장을 영상과 음식으로 탐색하는 모바일 중심 React 앱입니다. OpenAPI의 P0·P1 고객/상인 API를 연결했습니다.

## 실행

의존성이 설치된 상태에서 다음 명령을 실행합니다.

```sh
npm run dev
npm run build
npm run lint
```

## 구현 범위

- `/`, `/shorts`: 화면 단위로 세로 스냅되는 숏폼 피드. 현재 보이는 영상만 재생하며 커서 기반으로 다음 페이지를 조회합니다.
- `/markets`: 시장 검색, 지도 썸네일 영역·주소·가게 수·대표 음식이 있는 세로 카드 목록
- `/markets/:id`: 시장 내 가게의 메뉴 검색·분류, 음식 사진 영역·가격·가게·길찾기가 있는 세로 카드 목록
- `/videos/:id`: 영상 상세, 한국어·영어·중국어 VTT 자막
- `/profile`: 영어(기본)·한국어·중국어 선택 및 localStorage 저장. 선택 언어는 화면, API lang, 영상 자막에 반영됩니다. 기존 저장 언어는 유지합니다. 사장님 도구는 이 화면에서 접근합니다.
- `/stores/:id`: 메뉴 체크박스 선택, 가격, 시장 위치와 하단 합계·한국어 주문 이동 버튼
- `/stores/:id/order`: 수량 조절, 먹는 방법, 한국어 주문 카드와 현장 결제 안내. API `/orders/preview`로 문장·번역·합계를 생성합니다. 결제·주문 접수 API는 제공되지 않습니다.
- `/contents`, `/contents/:id`: K-콘텐츠 → 음식 → 가게 연결, 직접 매칭이 없으면 유사 음식 추천
- `/merchant`: 시장 선택 → 텍스트/녹음/음성 파일 답변 → 인식 내용 수정·확인/재답변 → 5단계 요약·영문 미리보기 → 가게 게시
- 상인 영상: 사진 3~5장, 선택 메뉴·음성·자막 언어 → multipart 요청 → 2초 작업 폴링 → 완료 영상, 실패 재시도
- 상인 관리: 가게 번호로 조회, 가게·결제 수단·메뉴 정보 수정 및 번역 재생성

React Router와 TanStack Query를 사용합니다. 로딩·빈 결과·API 오류 재시도, 모바일 하단 내비게이션, 콘텐츠 하단 패널 키보드 초점 제어를 포함합니다. 언어, 등록 세션, 가게 번호, 영상 작업 번호를 로컬에 저장합니다. 녹음은 마이크 권한과 HTTPS 또는 localhost 환경이 필요하며 음성 파일과 텍스트도 사용할 수 있습니다.

## API 설정

기본 API: `https://hack.220-66-233-75.nip.io/api/v1`

개발 모드에서는 Vite의 `/api`, `/media` 프록시를 사용합니다. API 서버가 특정 로컬 출처만 CORS 허용하기 때문에 로컬 주소에 따른 차단을 피하도록 구성했습니다. 프로덕션도 `/api/v1` 상대 경로를 사용하고, 루트 `vercel.json`에서 API 서버로 전달합니다. `/media`는 영상·썸네일·자막을 전달하며, 나머지 앱 경로는 `/index.html`로 연결됩니다.

다른 서버를 사용할 때 `.env.local`에 아래 값을 설정합니다. 빌드 후 서비스하는 출처는 해당 API 서버의 CORS 허용 대상이어야 합니다.

```dotenv
VITE_API_BASE_URL=https://your-api.example.com/api/v1
```

상대 미디어 주소는 API 서버 출처를 기준으로 해석합니다. API 계약은 `openapi.json`에 보관했습니다. Vercel의 SPA fallback 설정이 포함되어 중첩 경로에서도 새로고침이 가능합니다.

## 검증

- `npm run build`: 통과
- `npm run lint`: 오류·경고 없이 통과
- 390px 모바일 Edge: 실제 API 시장 → 가게 → 메뉴 2개 → 한국어 주문 카드/8,000원 확인
- 실제 API: 숏폼·자막 표시, 콘텐츠의 유사 음식/가게 연결, 영어 전환, 동영상·썸네일·자막 파일 HTTP 200 확인
- 사장님 화면: 브라우저 모의 API로 5단계 답변·확인 → 요약 → 게시 → 사진 multipart 업로드 → 2초 폴링 → 영상 완료, 가게·메뉴 PATCH 검증
- 상인 검증은 실제 서버에 가게 등록·수정·영상 생성 데이터를 남기지 않았습니다. 실제 AI 생성 결과와 마이크 장치 녹음은 별도 확인 대상입니다.

화면은 데스크톱에서도 최대 390px로 가운데 정렬되며, 더 작은 화면에서는 가용 폭에 맞춰 줄어듭니다. 디자인 참고 이미지와 환경 파일은 Git에서 제외합니다.


최근 숏츠·프로필 변경 검증은 GET 요청만 사용했습니다. 브라우저에서 세로 넘김, 화면 밖 영상 정지, 390px 데스크톱 정렬, 세 언어의 API 조회·새로고침 유지와 가게 메뉴 이동을 확인했습니다. 좋아요 수 등 API가 제공하지 않는 데이터는 추가하지 않았습니다.


## 4.jpg 화면 구성 반영

- 메인 포인트 색상은 `#9B4A2F`입니다. 피드, K-콘텐츠, 마이페이지를 390px 화면에 맞춰 구성했습니다.
- K-콘텐츠는 기존 API 데이터로 검색·분류 필터·2열 작품 카드·실제 음식/가게를 보여주는 하단 패널을 제공합니다. 순위와 이용자 수를 임의로 생성하지 않습니다.
- 마이페이지에서 UI 언어와 영상 자막 언어를 각각 설정할 수 있습니다. 최근 본 가게, 좋아요, 영상 저장은 기기 내 localStorage에 저장합니다.
- 사장님 진입은 기존 등록·관리 화면으로 연결하며, 별도의 인증 기능을 가정하지 않습니다.
- 브라우저에서 테마, 기기 내 저장, 최근 본 가게, 자막 설정, 콘텐츠 분류/음식 패널, 데스크톱 390px 폭을 확인했습니다. 직접 API 검증은 조회 요청만 사용했습니다.
